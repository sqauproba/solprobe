# Examples

Working examples for each way you can use SolProbe.

- `basic-cli/` — quick CLI walkthrough
- `python-sdk/` — using the Python SDK
- `typescript-sdk/` — using the TypeScript SDK
- `wallet-monitoring/` — watch a wallet over time
- `custom-alerts/` — write and load custom alert rules
- `docker-deployment/` — run the full stack with Docker Compose
