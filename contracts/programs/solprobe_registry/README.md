# solprobe-registry (optional Anchor program)

An on-chain registry that SolProbe can optionally use to track RPC providers,
watch targets, and alert rules on Solana. This is an *optional* component —
SolProbe works fully without any on-chain presence.

## Status

Scaffold only. The program is not yet built or deployed.

## Layout

- `Cargo.toml` — Anchor workspace manifest
- `src/lib.rs` — program entrypoint
- `Anchor.toml` — Anchor configuration
